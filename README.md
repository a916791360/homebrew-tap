# homebrew-tap

Official Homebrew Tap for [LaunchCloak](https://github.com/a916791360/LaunchCloak).

## Installation

```bash
brew install a916791360/tap/launchcloak
```

Or tap first:

```bash
brew tap a916791360/tap
brew install --cask launchcloak
```

## Upgrade

```bash
brew upgrade launchcloak
```
